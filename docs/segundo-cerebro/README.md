## Limites desta cópia

- O cofre original permanece em outra pasta e não foi alterado.
- `.obsidian/`, arquivos Canvas, notas sem conteúdo e configurações locais foram excluídos.
- Caminhos absolutos da máquina foram substituídos por marcadores como `<CAMINHO_LOCAL_DO_REPOSITORIO>`.
- Não foram incluídos `.env`, chaves, tokens, service accounts, dados de usuários ou credenciais.
- O nome do secret `GEMINI_API_KEY` aparece apenas como documentação operacional; nenhum valor aparece.
- Git, Firebase, Cloudflare e o ambiente vivo continuam sendo as fontes de verdade do código e da infraestrutura.
