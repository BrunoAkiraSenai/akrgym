# AkrGym — protocolo de colaboração

## For future agent
Registro append-only da decisão de colaboração tomada em 2026-09-17. A nota não contém credenciais; o estado vivo do código deve ser conferido no GitHub e no repositório.

## Decisão

- proprietário do AkrGym adicionará outro programador ao projeto.
- O colaborador codifica, testa, commita e envia somente para `QA`.
- Bruno revisa e é o único responsável por promover para `PRD` e publicar no site.
- O colaborador deve executar `git fetch origin --prune`, `git switch QA` e `git pull --ff-only origin QA` antes de iniciar e sincronizar novamente antes do handoff.
- Push, merge, deploy, reset destrutivo e force push em `PRD` são proibidos para o colaborador.
